# POS Pro Desktop

A desktop POS app built with Electron for sales, product management, inventory tracking, customer records, and basic reporting.

## Features
- Sales register with cart and receipt preview
- Product catalog management
- Barcode-based item lookup
- Inventory level monitoring
- Customer list management
- Business summary and reports
- Local offline storage with browser `localStorage`

## Run the app

```bash
npm install
npm start
```

## Build a Windows desktop app

```bash
npm install
npm run dist:win
```

This creates Windows installer and portable executable files in the `dist` folder so you can double-click them to run.
